Mode Aman

Memuat…

Saat mode aman menyala, seluruh perintah ke ONU dihentikan — simpan WAN, simpan SSID, reboot, bahkan Refresh. Pembacaan data tetap berjalan normal, sehingga keadaan armada tetap terpantau. Perintah yang telanjur mengantre tetap bisa dibatalkan.

Yang selalu ditolak

Ditegakkan di server, bukan di browser — jadi tetap berlaku walau perintahnya dikirim langsung dengan curl, melewati tampilan ini. Daftar ini tidak dapat dimatikan dari sini: pagar yang bisa dibuka dari layar bukan pagar.

  • factoryReset, download, upload — tidak pernah dipakai panel, dan akibatnya tidak dapat dibatalkan.
  • Menulis ManagementServer.* — kredensial ACS dan interval adalah wilayah provision GenieACS. Bila panel ikut menulis, dua penulis berebut nilai yang sama dan ONU menerima penulisan flash bergantian tanpa henti.
  • Refresh seluruh pohon — pada HWTC ZL-2113X (±450 ms per perintah) itu menahan CPU-nya menit-menitan.
  • Membaca ManagementServer — password di sana write-only; ONU membalas kosong, cache tercemar, lalu provision menulisnya ulang ke flash setiap sesi.
  • Menghapus objek terlalu dekat akar — misalnya seluruh WANDevice.1 dalam satu perintah.
  • Perintah bertanda koma / lebih dari 32 parameter — bentuk cacat yang gagal di setiap sesi ONU selamanya.
  • Mengubah provisions, virtual parameters, presets, dan files di GenieACS — itu kode yang berjalan pada setiap sesi setiap ONU; perubahannya dilakukan manual dengan prosedur. Membacanya tetap boleh.

Reboot sengaja TIDAK dilarang — itu perkakas sah teknisi. Yang berubah: setiap reboot kini tercatat di jejak audit berikut siapa yang mengirimnya.

Kesehatan ACS

Kegagalan perintah, antrean yang menggantung, dan dari mana sumbernya

Murni baca — tidak mengirim apa pun ke ONU.

Perintah yang gagal

Antrean perintah di GenieACS

Perintah yang mengantre dijalankan saat ONU-nya inform berikutnya — kapan pun itu. Perintah milik panel dibatalkan otomatis bila belum dijalankan dalam 30 menit, agar tidak berlaku mendadak di kemudian hari.

Bersihkan antrean lama

Menghapus perintah yang mengantre lebih dari 24 jam atau yang cacat (gagal "Invalid parameter path" di setiap sesi) — dari alat mana pun, termasuk UI GenieACS. Tidak ada yang dikirim ke ONU; justru mencegah perintah basi berlaku mendadak. Salinan setiap perintah disimpan ke data/backup/ sebelum dihapus.

Vendor Configuration

Konfigurasi prefix path parameter WAN/akun per product class ONU (PPPoE, Bridge, DHCP, Static IP)

Cara kerja: Setiap vendor ONU memiliki path TR-069 yang berbeda untuk konfigurasi akun WAN. Dengan mendefinisikan template di sini, panel bisa secara otomatis mengkonfigurasi akun WAN di semua vendor tanpa mengubah kode.

Contoh ZTE (TR-098): WAN Root: InternetGatewayDevice.WANDevice.1.WANConnectionDevice.1. | PPPoE User: WANPPPConnection.1.Username | Conn Type: WANIPConnection.1.ConnectionType | Bridge: IP_Bridged

Mode: PPPoE • Bridge • DHCP • Static IP

PRODUCT CLASS WAN ROOT PATH PPPoE PATH CONN TYPE PATH ACTIONS
Belum ada konfigurasi — klik Add Vendor Config untuk menambah

Security Setting

Konfigurasi parameter WiFi/SSID per product class — BeaconType, EncryptionMode, dan path password per vendor

Cara kerja: Vendor ONU berbeda menggunakan BeaconType dan path parameter SSID yang berbeda. Konfigurasi di sini memungkinkan panel mengatur SSID & password WiFi di semua jenis ONU secara otomatis saat konfigurasi di halaman detail perangkat.

Contoh ZTE F663NV9 (X_CMCC): Password Path: KeyPassphrase | BeaconType WPA: WPA/WPA2 | BeaconType Open: None | BasicEncryptionModes: None

Konfigurasi digunakan otomatis saat mengatur SSID di halaman detail perangkat
